## 核心约束

1. 不直接复制第三方构建后的 JS / CSS 或完整 UI 资产到正式 Android 原生工程。
2. 不把静态清单等同于含音频、题目、解析的可运行学习功能。
3. 原版已知入口必须记录“已实现 / 样本 / 待接入 / 待验证”，不能静默删除。
4. 交互等价验收为：操作入口、状态切换、返回行为、错误提示、过程与结果一致；视觉布局允许重构。
5. 系统手势、TalkBack、字体缩放、屏幕旋转、输入法、手机/平板布局均单独验收。
6. 本地统计必须来自用户真实操作，原版在线账户、打卡与排行无法直接从静态资源迁移。

## 实施阶段

- **P0**：原生底座、首页、样本练习、保存状态、CI 构建
- **P1**：原版题目抽屉、自制听写键盘、查词、复杂笔试结构
- **P2**：合法内容源、真正音频/逐句索引、Media3、完整词书
- **P3**：统计日历与设备间同步，真机 1:1 操作回归和发布

## 最新原版源码核对（2026-11-19）

- 原版静态资源拆分到 `recovered-source/jingting/js/` 的 41 个 JS 文件与 `css/` 的 19 个 CSS 文件。它们是浏览器前端模块，不是 Android 原生源码。
- `ui_arena_controls.js` 题目抽屉包含题号及切题事件。原生对应 `PracticeJumpSheet` 和 `WrittenSession`，示例已能跳题和标记完成；原版多题型分组未迁移。
- `dictation_controls.js` 的句子抽屉支持句子跳转。原生 `DictationSession` 已建立句子索引；答对句子的状态仅保存在此练习会话，并非真题进度。
- `dict_virtual_keyboard.js` 自制 26 键可以切换到系统键盘，另含长按退格、换空、提示、答案等功能。原生已完成 26 字母、退格、收起、系统键盘切换，暂未迁移长按和多空换空。
- `written_exam.js` 包含跨题答题状态和成绩。原生示例使用 `AnswerLedger` 保证每道题首次提交只记一次；页面切换可恢复会话状态；正式试卷级恢复未实现。
- `exam_loader.js` 提供按模块请求 JSON 的代码，并不证明完整试卷资源可用。
- `toy_sdk.js` 仍使用第三方用户数据与排名接口，不能当成独立 App 的账号后端。

### 功能等价分级

- **已有示例可交互代码**：题号抽屉、跳题、已答标记、逐句索引、26 键、退格、键盘切换。
- **仍不等价**：复杂题型分组、题目长文阅读、单题多空、自制键盘长按退格、多空换空、原声时间轴、离线音频。
- **尚未接入**：正式英语考试题目及音频、完整词书、原版用户云同步与排行。
- **验证要求**：CI 编译与单测、Android 真机交互检查均通过后才能认定可发布。`AnswerLedgerTest` 仅覆盖逻辑，不代表 UI 验收。

第三方代码仅用于理解公开界面行为。未经授权不直接将其构建产物、资源或受保护实现移植至正式 Android 软件。

## 大学英语内容范围（新增）

以原版 `exams_manifest.js` 的四级 74、六级 51、雅思 72、考研英语 34 套为唯一目标目录，不包含高考。`UniversityRepository` 只允许 `cet4/cet6/ielts/kaoyan` 四种数据键。原版资料在构建时写入 APK assets，并通过索引验证；若校验不全则不得把产物命名为完整离线版。

`UniversityScreens` 已提供真实数据驱动的基础练习界面，但其题型解析和音频时间轴尚须针对真实下载内容验收，不能宣称所有题型等价。许可由项目用户确认，打包前仍应确保许可覆盖原版音频、题目、解析、词库及再发布行为。
